# User Account Audit Tool

This project simulates a basic identity and access management (IAM) audit process by analyzing user account data.

## Purpose
To identify inactive, duplicate, or incomplete user accounts that may pose security or operational risks.

## Features
- Detects inactive users
- Identifies duplicate accounts
- Flags missing email addresses
- Outputs a clean audit report

## Tools Used
- Python
- CSV data handling

## Why I Built This
As an IT Support Specialist, I regularly work with user account management and access control. This project demonstrates how basic auditing can improve security and system organization.
